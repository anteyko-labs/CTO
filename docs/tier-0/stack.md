# Технологический стек

Стек консервативный и зафиксированный. Новая библиотека или сервис добавляется только через запись в `docs/tier-5/decisions.md`.

## Сервер

| Назначение | Выбор |
| --- | --- |
| Язык | Rust (stable) |
| HTTP | Axum на Tokio |
| Доступ к БД | SQLx с проверкой запросов на этапе компиляции |
| Миграции | `sqlx migrate` |
| Сериализация | serde |
| Ошибки | thiserror; `Result<T, E>` везде |
| Хеширование паролей | argon2 |
| Логи | tracing |
| Идентификаторы | UUID v7 |

## База данных

PostgreSQL 16 — единственный источник правды. Операции, меняющие остатки и деньги одновременно, выполняются одной транзакцией.

Redis и брокер очередей в первой версии не используются: сессии хранятся в PostgreSQL, фоновых задач мало, и они выполняются внутри сервера.

## Клиент

| Назначение | Выбор |
| --- | --- |
| Язык | TypeScript |
| UI | React + Vite |
| Стили | Tailwind CSS |
| Офлайн | PWA: Service Worker (Workbox) + IndexedDB |
| Штрихкоды и QR | Генерация на клиенте, печать через диалог печати браузера |
| Печатные формы | HTML-шаблоны с CSS для печати |

Одно приложение на все устройства: моноблок на кассе, ноутбук на складе, телефон владельца. Установка из браузера, без магазинов приложений.

## Оборудование на точке

| Место | Устройства |
| --- | --- |
| Касса | Моноблок, сканер штрихкодов (режим клавиатуры) |
| Склад | Ноутбук, принтеры этикеток |
| Владелец | Телефон |

Сканер работает как клавиатура, драйверы и отдельные программы не требуются. Размеры этикеток задаются настройкой под конкретные принтеры.

## Развёртывание

- Один сервер, Docker Compose: приложение, PostgreSQL, обратный прокси с HTTPS.
- Резервная копия базы — ежедневно, с хранением вне сервера.
- Секреты только в переменных окружения, в репозитории их нет.

## Единицы хранения

| Величина | Тип | Единица |
| --- | --- | --- |
| Деньги | `BIGINT` | тыйын (1 сом = 100) |
| Объём жидкостей | `BIGINT` | миллилитр |
| Штучный товар | `BIGINT` | штука |
| Время | `TIMESTAMPTZ` | UTC, показ в Asia/Bishkek |

## Не используем в первой версии

Redis, RabbitMQ, gRPC, отдельные сервисы-воркеры, голосовой и чат-ввод, нативные мобильные приложения, интеграции с ККМ и платёжными терминалами.
