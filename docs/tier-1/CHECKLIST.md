# Чек-лист до рабочего продукта

Порядок сверху вниз. Пункт считается сделанным, когда есть код, тесты и документация в одном коммите, а проверки CI зелёные. Этапы — из BLUEPRINT §4, спецификации — `docs/tier-4/`.

## 0. Этап 1 «Ядро» — сделано

- [x] Вход, роли, журнал действий, идемпотентность операций (SPEC-01)
- [x] Категории, товары, характеристики, свои штрихкоды, этикетки, справочники (SPEC-02)
- [x] Приход, средняя себестоимость, остатки, проверка остатков (SPEC-03)
- [x] Касса: продажа, розлив, возврат, оплата (SPEC-04)
- [x] Развёртывание в контейнерах, проверки в CI, сквозные тесты в браузере

## 1. Правки по ответам заказчика от 2026-10-06

- [x] Штрихкод обязателен: автогенерация при создании товара, миграция старым товарам (ADR-026)
- [x] Несколько штрихкодов в интерфейсе: список, добавить, отвязать, запрет на отвязку последнего
- [x] Неизвестный код при сканировании: «Привязать к товару» рядом с «Создать товар»
- [x] Остатки масла считаются литрами: «14,5 л · 3 кан. по 4 л + 2,5 л» (SPEC-03)
- [x] Замена масла — отметка чека, а не строка услуги; ставка 30 сом за чек в настройках (ADR-027)
- [x] Формы не отправляются с незаполненными обязательными полями, рядом с кнопкой видно, чего не хватает
- [ ] Клиент в чеке (`party_id`) для истории покупок — заводится вместе с этапом 3
