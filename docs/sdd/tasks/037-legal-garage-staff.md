# 037 — Гаражи юрлица, подтверждения, пересчёт долга, график, временный сотрудник, агент

Статус: утверждено (14.11.2026; ответы 5а, 6в, 7а, 8а, 9а, 10а с возможностью б, 11а)

## Зачем
Заказчик 14.11.2026: «регистрация машин юрлиц в 2 форматах: личный гараж — машина человека, но оплачивает компания, в боте; гараж юрлиц — в личном кабинете»; «система запросов для подтверждения»; «пересчёт для отдельного клиента»; «график выходных: Айкос не менее 1, Автодом не менее 2»; «временный сотрудник»; «торговый агент — моторист, кто направляет в магазин». QR на доп. экране — уже есть (задача 008), не делаем.

## Что меняется
1. **Гараж фирмы (кабинет).** Руководитель в кабинете юрлица добавляет машину фирмы (номер, марка, модель) — она приходит запросом (п. 3).
2. **Личный гараж (бот).** Работник фирмы в боте: «🚗 Добавить машину» → номер, марка → «Оплачивает фирма: <название>». Машина — личная машина работника, долг за её обслуживание записывается на фирму (ответ 5а); в покупках фирмы видно «личная машина <имя>».
3. **Запросы на подтверждение** (ответ 6в). Машина/водитель из бота или кабинета — «Ждёт подтверждения»: не выбирается на кассе в долг фирмы, пока не подтвердит руководитель фирмы (кабинет, «Запросы») или владелец/администратор с правом «Клиенты и машины» (карточка фирмы, «Запросы»). Достаточно одного. «Отклонить» — с причиной; автору — сообщение в бот. Событие владельцу `party.vehicle_request`.
4. **Пересчёт долга клиента** (ответ 7а). В карточке клиента (владелец): «Пересчитать долг» — сервер суммирует `party_ledger` по филиалам и сравнивает с балансом; расхождение — показывает и исправляет баланс по журналу долга (I6), запись в журнал действий; без расхождения — «Совпадает». Акт сверки по одному клиенту — как сейчас.
5. **График выходных** (ответ 8а). «Сотрудники → График»: месяц, по строке на работника, клик — выходной. Нельзя поставить выходной, если в этот день в филиале работающих станет меньше минимума — 409 «В <день> останется N, нужно не менее M». Минимум — настройка филиала `staff.min_on_duty` (0 = без ограничения, по умолчанию; владелец ставит Айкос 1, Автодом 2). Право «График выходных» (новое, не по умолчанию); владелец — всегда.
6. **Временный сотрудник** (ответ 9а). В карточке — «Работает до <дата>». После даты: сотрудник не выбирается мастером/кассиром, PIN и личный вход не действуют; начисленное остаётся к выплате; продлить — сменить дату.
7. **Торговый агент** (ответ 10а, с возможностью б). Справочник «Агенты» (общий на филиалы: имя, телефон, «Процент агенту» — по умолчанию 0). В кассе — необязательное поле «Кто направил». Отчёт «Агенты» (владелец): по агенту — чеков, сумма; если процент > 0 — «Агенту причитается N с»; выплата — расходом «Агенту» из существующих расходов.

## Данные, маршруты, права
- Миграции 0112–0114 (0111 занята задачей 038): `vehicles.status` (`active`/`pending`/`rejected`, по умолчанию `active`), `vehicles.paid_by_party_id`, `vehicle_requests` (кто, откуда, решение, причина; append-only); `employee_days_off(employee_id, day, branch_id)`, `employees.active_until date null`; `agents` и `sales.agent_id null`.
- `POST /client/vehicles`, `GET /client/requests`, `POST /client/requests/{id}/approve|reject`; `GET /parties/{id}/requests`, `POST /parties/{id}/requests/{id}/approve|reject`; `POST /parties/{id}/recount` (владелец); `GET|PUT /staff/days-off`; `GET|POST|PATCH /agents`, `GET /reports/agents`. Всё — с `op_id`, в обход `branches.rs`.
- Право `staff_schedule` «График выходных» (группа «Справочники», не по умолчанию; прав 36, по умолчанию 26). События: `party.vehicle_request`, `party.recount`, `staff.day_off`.
- ADR-199: машина с оплатой фирмой и подтверждение (ADR-198 занят задачей 038).

## Не входит
Свой бот на филиал; выплата агенту отдельной ведомостью; график смен по часам; QR на доп. экране (есть).

## Решено без вопроса
- Минимум по умолчанию 0 (прежнее поведение, I21); значения 1/2 владелец ставит в настройках.
- Процент агенту по умолчанию 0 — это вариант «а»; «б» включается процентом.
