# 012 — несколько штрихкодов у нового товара в ревизии

Статус: сделано (02.11.2026)

## Зачем
Владелец 02.11.2026: «в ревизии новый товар… возле поля штрихкод плюс кнопку сделать, нажимаешь — и можно ещё штрихкод ввести сразу, для одной позиции много штрихкодов». У заведённого товара коды добавляются в карточке, а при заведении из ревизии — только один.

## Что меняется
- Окно «Товар, которого нет в программе» (`RevisionNewProduct.tsx`): у поля «Штрихкод» кнопка «+» добавляет ещё одно поле кода (сколько угодно), у каждого добавленного — «×». Уходят все коды без пустых и повторов, основной — первым (`barcodesOf`, `lib/barcodeTaken.ts`).
- Сервер не меняется: `POST /revisions/{id}/new-product` уже принимает `barcodes[]` (занятый код — 409, как раньше). «Товар только что завёл другой» проверяется по первому коду.
- Экраны, права, данные, уведомления — без изменений.

## Не входит
Несколько кодов при заведении в кассе, приходе и «Сканере товаров».

## Проверка
- `web/src/lib/barcodeTaken.test.ts` — `barcodesOf` (порядок, пустые, повторы).
- e2e `web/e2e/revision-new-barcodes.spec.ts` — четыре кода, пустое поле не уходит, товар находится по каждому.
