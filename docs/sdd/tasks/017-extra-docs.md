# 017 — Другие документы точки: договоры правятся и печатаются в «Документах»

Статус: сделано (заказчик 02.11.2026: «пока без подписи Имана — просто документ редактируемый, и там же, где шаблоны, их напечатать можно; туда ещё трудовой договор шаблон сделай и залей на рабочую версию»).

## Что сделано
1. «Настройки → Документы» (экран переименован из «Документы о долге»): блок «Другие документы» — список договоров; у каждого «Печать» (2 экземпляра A4), «Удалить», раскрытие: название, текст, предпросмотр, «Вернуть исходный текст» (для шаблонов по умолчанию). «Добавить документ». Сохранение — общей кнопкой «Сохранить».
2. Подстановки: `{{дата}}` (сегодня), `{{город}}`, `{{продавец}}`, `{{инн_продавца}}`, `{{адрес_продавца}}`, `{{телефон_продавца}}`, `{{руководитель}}`, `{{подпись_продавца}}` — подпись руководителя ставится сама (ADR-179). Подписи второй стороны с планшета нет — ручкой.
3. Шаблоны по умолчанию: «Договор об ответственности за товар на складе» (доли в процентах, ревизия, недостача по долям, 30 дней, расторжение) и «Трудовой договор» (по трудовому законодательству КР: должность, срок, испытание до 3 мес., режим, отпуск не менее 28 к. д., оплата, обязанности, материальная ответственность, расторжение). Тексты — не от юриста: показать юристу.
4. Сервер: `debt_docs.extra` (`Option<Vec<{title,text}>>`) в `PUT/GET /settings/debt-docs`; `null` — не сохраняли; проверки: не больше 30, название 1–200, текст до 40 000; только владелец.

## Данные рабочей версии
В облако занесён договор об ответственности Канатбеков И. К. — 86 %, Гайбулин А. И. — 14 % (паспортные данные — в тексте документа в базе, не в git) и трудовой договор по умолчанию.
