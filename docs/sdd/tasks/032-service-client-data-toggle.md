# 032. Переключатель «Данные клиента обязательны» в чеке «В сервис»

Статус: сделано

## Зачем
Заказчик (04.11.2026): «нужно чтоб владелец мог в настройках кассы через тумблер переключать обязательность заполнения данных клиента, оставить только обязательно мастера указывать».

## Как сейчас (по коду)
- Чек «В сервис» требует клиента, телефон, машину с госномером и пробег (ADR-100, SPEC-30 §3). Сервер: `server/src/api/sales.rs:706`, `:1618`. Касса: `web/src/lib/serviceSale.ts:149`, `web/src/pages/Cashier.tsx:1276`.
- Мастер обязателен отдельно: `server/src/api/sales.rs:1393`.

## Что меняется
1. В «Настройки → Касса», карточка «Смена», — один переключатель «Данные клиента в чеке «В сервис» обязательны» (`service_client_required`). Настройка филиала, по умолчанию включено — как сейчас (I21). Меняет только владелец, изменение пишется в журнал, повтор `op_id` — тот же ответ (I5, I8).
2. Включено — всё как сейчас.
3. Выключено — чек «В сервис» проводится без клиента, телефона, машины и пробега:
   - сервер не отвечает 422 из-за этих данных;
   - касса не показывает подсказку о недостающем и не блокирует «Провести»;
   - чек без сети не даёт владельцу уведомление «в сервис без данных клиента».
4. Мастер и вид замены обязательны при любом положении переключателя: без них касса не проводит чек, сервер отвечает 422.
5. Выключено, но данные указаны — они сохраняются как обычно. Машина указана без пробега — запись в книжке ТО без пробега, следующая замена считается только по дате.
6. Продажа в долг и «По счёту» по-прежнему требуют клиента (и ПИН или ИНН для долга): это правила денег, переключатель их не меняет.
7. Касса без сети берёт значение из снимка настроек; окончательно решает сервер (I10).

- Экраны: «Настройки → Касса» — переключатель с пояснением; касса — без обязательных отметок при выключенном.
- Маршруты: новых нет; `GET/PUT /settings/cashier` — новое поле.
- Данные: миграция не нужна — поле в JSON настроек, нет поля — значение по умолчанию.
- Права: только владелец, как у остальных настроек кассы (I12, I21).
- Уведомления: новых нет.
- ADR: ADR-191 — уточнение ADR-100 и SPEC-16 (пробег при выбранной машине).

## Не входит
- Отдельные переключатели на телефон, машину и пробег.
- Правила обычной продажи, долга и счёта.
- Изменение уже проведённых чеков.

## Решено без вопроса
- Один переключатель на все данные клиента: так в просьбе.
- По умолчанию включено: I21 — прежнее поведение, пока владелец не переключит.
- Настройка своя у каждого филиала, как остальные настройки кассы.
- Пробег при выключенном необязателен и при выбранной машине: «обязательно только мастера».

1. Вид замены при выключенном переключателе — ответ заказчика (04.11.2026): остаётся обязательным всегда, от него считается оплата мастеру (ADR-096).
