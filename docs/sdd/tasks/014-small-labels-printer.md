## Зачем
Владелец 02.11.2026: «на складе был 1 принтер, теперь ещё 1 появился для маленьких этикеток 2 на 3… кнопка печать на складе — ту что была, напиши „большой штрихкод“, а для второго — маленький; ещё надпись „Цена“ нужно вернуть». Сейчас размер этикетки один (`LabelSettings` в `refs.rs:1338`), станция печатает всё на принтер по умолчанию (задача 006 Н3).

## Что меняется
- **П1 Два размера.** Настройки этикеток — два набора: «Большая» (нынешние, ключ `labels`, без изменений) и «Маленькая» (новый ключ `labels.small`, по умолчанию 30×20 мм, штрихкод + «Цена: …», без названия, бренда, характеристик и артикула). «Настройки → Этикетки» — две вкладки, тот же журнал `settings.labels` (I21).
- **П2 Кнопки.** Везде, где сейчас печать этикеток (`Products`, карточка нового товара, `ReceiptNew`, `ReceiptView`, `StockInView`), вместо одной кнопки — две: «Большой штрихкод» и «Маленький штрихкод». Выбор «Здесь» / «На складе» (`labelTarget.tsx`) убрать: обе кнопки всегда отправляют на склад. Настройку `labels.remote_default` убрать из экрана (ключ в базе не трогать). Без сети кнопки недоступны с подсказкой «Печать — только на складе, нужна сеть». Уточняет задачу 006 Н2/Н5.
- **П3 Очередь.** `label_jobs.size text not null default 'big' check (size in ('big','small'))` — миграция `0100_label_size.sql`. `POST /label-jobs {op_id, items, size}` (без `size` — `big`, старые телефоны работают). `POST /label-jobs/take {station_id, size}` берёт только задания своего размера.
- **П4 Станция.** `/label-station?size=big|small`: экран показывает «Принтер: большие этикетки» / «маленькие», берёт свои задания, печатает по своим настройкам, «Пробная этикетка» — своего размера. На компьютере склада — два окна Chrome с разными профилями (`--user-data-dir`), каждое с `--kiosk-printing` и своим принтером; инструкция — в SPEC-02. `station_online` — по размеру (`label_stations.size`): нет маленькой станции → на телефоне «Маленький принтер не в сети».
- **П5 «Цена».** Подпись «Цена: …» на обоих размерах (в main уже есть с ea12b87, на 8080/облаке ещё нет — уйдёт с выкатом). На маленькой этикетке цена — отдельной строкой крупно, не обрезается.

## Не входит
Выбор принтера из программы (браузер этого не умеет — только через профиль Chrome). Третий размер. Ценники на полку.

## Проверка
- `server/tests/label_jobs.rs`: задание `small` не берёт станция `big` и наоборот; без `size` → `big`; `station_online` по размеру; настройки `small` сохраняются отдельно, границы 10..200 мм.
- `web/src/lib/labelJob.test.ts` — `size` в теле; `labels.test.ts` — у 30×20 есть «Цена:» и штрихкод, нет названия, у 40×30 — «Цена:».
- e2e `label-station.spec.ts`: две станции (`?size=big`, `?size=small`), «Маленький штрихкод» → печатает только маленькая; «Большой штрихкод» → только большая.
- `cargo sqlx prepare -- --all-targets` на `avtodom_e2e*`, `python3 scripts/registry.py`, `./scripts/sdd-review.sh`.

## Решено без вопроса
- Старая кнопка и её настройки = «Большой штрихкод» (слова владельца).
- Маленькая этикетка — 30 мм ширина × 20 мм высота (обычная ориентация рулона 2×3); размер можно поменять в настройках.

## Ответы владельца
1а — оба принтера на одном компьютере склада. 2б — маленькая: штрихкод + цена. «Здесь» не нужен — печать только на складе.

1. Новый принтер подключён к тому же компьютеру на складе, что и старый? а) да, к тому же; б) к другому компьютеру/ноутбуку.
2. Что печатать на маленькой этикетке? а) название + штрихкод + цена; б) только штрихкод + цена; в) только штрихкод.
