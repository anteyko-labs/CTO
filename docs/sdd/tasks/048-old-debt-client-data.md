# 048 — Данные клиента со старым долгом: правка на месте и полные данные при новом долге

Статус: сделано (утверждено 22.11.2026, владелец: «1 то же что и в автодоме, 2 а»; правят владелец и администратор)

## Зачем
Владелец 22.11.2026: «старые долги — возможность редактировать ФИО на месте, всё что нужно;
если человек со старым долгом пришёл и хочет ещё взять — пусть все данные возьмём, и с подписью».
Сейчас у 93 клиентов со старым долгом из тетради: у 82 нет ПИН, у 38 нет телефона. Касса при долге
только подсказывает «нужен ПИН» и не мешает провести; подпись клиента за долг уже обязательна
(задача 008).

## Что меняется
1. **Правка на месте.** «Долги» и «Старый долг»: у строки клиента — «✏️» → окно «Данные клиента»:
   фамилия, имя, отчество (физлицо) или название (фирма), телефон, ПИН/ИНН, адрес. «Сохранить» —
   `PATCH /parties/{id}` (как в карточке клиента, журнал `party.update`, I5). Право — «Клиенты»
   (`clients`), владелец — всегда. Неполные данные — в строке метка «нет ПИН · нет телефона».
2. **Новый долг — только с полными данными.** Чек с долгом (весь или часть) не проводится, пока в
   карточке не заполнено обязательное (см. вопрос 1): касса показывает окно «Данные клиента» с
   пустыми полями, «Записать» — в карточку, затем подпись клиента на планшете (как сейчас) →
   «Провести». Сервер: долг > 0, а обязательного нет — 422 «Заполните данные клиента: …».
   Без сети — чек в очереди, данные пишутся в карточку вместе с ним (I9).
3. Это для всех клиентов, берущих в долг, не только со старым долгом (иначе правило обходится
   новым клиентом).
4. Старые чеки и долги, документы о долге, акт сверки — без изменений; в новой расписке — уже
   полные данные.

## Ответы владельца (22.11.2026)
1. Физлицо — как в расписке Автодома: фамилия, имя, телефон, ПИН (14 цифр); паспорт в расписке вписывается от руки.
2. Фирма — название, телефон, ИНН.

## Вопросы владельцу (были)
1. Что обязательно для нового долга физлица?
   а) фамилия, имя, телефон, ПИН (14 цифр);
   б) а) + адрес;
   в) а) + адрес + номер паспорта (нужно новое поле).
2. Для фирмы обязательно:
   а) название, телефон, ИНН;
   б) а) + адрес.

## Проверка
- Сервер: долг без обязательного — 422; заполнили — проводится; без долга — данные не нужны;
  `PATCH` без права — 403; журнал правки.
- e2e: «Долги» → ✏️ → поправить ФИО → в карточке новое; касса: клиент без ПИН → долг → окно данных
  → подпись → чек проведён.

## Решено без вопроса
- Подпись остаётся обязательной для любого долга (уже есть).
