# 050 — Процент кассира с долгового чека — сразу (Айкос)

Статус: сделано (25.11.2026; ответ 1б; ADR-214)

## Зачем
Владелец 25.11.2026: «оплату в Айкосе сделай с валовой прибыли, даже если долг берут — считай, будто сразу оплатил, а не с чистой».
Сейчас (ADR-035, ADR-036) процент кассира идёт с валовой прибыли чека: с оплаченной части — сразу, с долговой — только при погашении (`payroll_pending`). В Айкосе 10 долговых чеков ждут погашения, это около 7 949 с процента (Маметтурдиев Эрбол, 15,5 % и 17,5 %).

## Что меняется
1. Настройка филиала «Процент кассира с долга — сразу» в «Настройки → Касса» (по умолчанию выключена). Владелец включает её в Айкосе.
2. Если включена: процент начисляется с валовой прибыли всего чека в момент проведения, долговая часть считается оплаченной. Ожидание погашения (`payroll_pending`) не создаётся, при погашении долга процент повторно не начисляется.
3. Возврат и «Изменить оплату» по такому чеку снимают процент так же, как у оплаченного чека.
4. Изменение настройки — в журнал (I21); действует для чеков после включения.
5. Уже ждущие долговые чеки (ответ 1б) — не трогаем: процент по ним придёт при погашении, как раньше.

## Данные, права
Поле в настройках кассы филиала (`cashier_settings`), миграции нет. Менять может только владелец.
