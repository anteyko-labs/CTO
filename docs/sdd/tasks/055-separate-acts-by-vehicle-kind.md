# 055 — Два отдельных акта сверки фирмы: машины фирмы и личные машины работников

Статус: сделано (27.11.2026; владелец: «нужно оказывается 2 разных акта сверки для личных машин и для машин юр лиц… срочно сделай и залей, разрешаю»; ADR-218)

## Зачем
Задача 051 показала долг фирмы двумя видами в одном акте. Фирмам нужны два отдельных акта: по машинам фирмы и по личным машинам работников (ADR-199), которые фирма оплачивает.

## Что меняется
1. **Акт по виду:** `GET /parties/{id}/reconciliation?kind=company|personal` и `GET /client/reconciliation?kind=…` (кабинет фирмы). Без `kind` — общий акт, как раньше.
2. **Строки:** чеки, возвраты и сторно — в акт своего вида (вид чека — `sales.vehicle_personal`, задача 051); старый долг, корректировки в плюс — «машины фирмы и прочее».
3. **Оплаты** по-прежнему гасят самый старый долг (ADR-073). В отдельном акте оплата стоит той частью, что ушла на этот вид; если делится — пометка «из N с — на личные машины / машины фирмы». Части — из `debt_personal_tyiyn` на конец каждого дня с движениями, поэтому сальдо отдельного акта = долг вида в карточке, а два акта вместе = общий акт. Редкий перенос между видами без оплаты в этот день (возврат уже оплаченного чека) — строкой «Перенос между видами долга».
4. **Сальдо на начало** — по видам на день до начала периода.
5. **Экран:** в окне акта у фирмы с чеками на личных машинах (`has_personal`) — кнопки «Общий · Машины фирмы · Личные машины»; печать и .xlsx — с подзаголовком «по машинам фирмы и прочему» / «по личным машинам работников», вывод — тоже по виду. То же в кабинете фирмы.

## Не входит
Акт по одному работнику, раздельные лимиты и погашение по видам.
