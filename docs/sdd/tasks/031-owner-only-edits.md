# 031. Право менять себестоимость в товарах

Статус: сделано (04.11.2026; ответ 1а; в main, не выкачено)

## Зачем
Заказчик (04.11.2026): «изменить цену прихода нужно тоже как право сделать, это можно и выдавать и не выдавать пользователям»; «в товарах можно было изменить цену себеса, там же есть такой пункт».

## Как сейчас (по коду)
- В карточке товара кнопка «Указать / Исправить цену закупки» — только у владельца: `web/src/components/ProductCostBlock.tsx:74`; сервер: `server/src/api/receipts.rs:1602` (`require_owner`). Исправление переоценивает весь остаток; проданное не меняется.

## Что меняется
1. Новое право `purchase_price` «Менять цену закупки товара», группа «Справочники», по умолчанию выключено; владелец выдаёт его каждому администратору отдельно.
2. С правом администратор видит в карточке товара «Указать / Исправить цену закупки» и проводит её в своём филиале тем же действием, что владелец.
3. Без права кнопки нет, сервер отвечает 403 «Нет права: Менять цену закупки товара» (I12).
4. Средняя себестоимость, стоимость остатка и наценка администратору по-прежнему не отдаются (I13); ответ и сообщение ему — без суммы начисления кассирам и суммы переоценки.
5. Владельцу приходит уведомление: кто, какой товар, была цена → стала. Новое событие `stock.purchase_price`, выключатель в боте.

- Маршруты: новых нет; `POST /stock/{id}/purchase-price` — проверка права. Бот владельца остаётся только для владельца.
- Данные: миграция `0107` — только дополняет проверку списка прав, существующим администраторам право не выдаётся.
- Права: 35, по умолчанию 26. Отступление от I14 — ADR (переоценка остатка — изменение учёта; сторно приходов не затрагивается).

## Не входит
- «Исправить» проведённого прихода: остаётся у владельца.
- Цена продажи: это право `prices`.
- Печать выбранных товаров: уже есть, заказчик подтвердил, менять не нужно.
