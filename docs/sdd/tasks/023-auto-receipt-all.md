# 023 — Товарный чек после любого чека печатается сам

Статус: сделано

## Зачем
Заказчик: «почему чек не печатается… нужно чтоб автоматом выводил чек» (03.11.2026). Сейчас касса
печатает товарный чек сама только после чека «В сервис» с машиной и только при настройке
`auto_receipt`; чек «На вынос» — только кнопкой «Печать чека».

## Что меняется
- Настройка в «Масляная книжка и печать», группа «Печать»: «Товарный чек после любого чека —
  печатать сам» — ключ `auto_receipt_all` в `settings.oil_book` (JSON, без миграции), по умолчанию
  выкл., меняет только владелец (как остальные ключи, `require_owner`).
- Включена → после проведённого чека любого типа (на вынос, в сервис; с машиной и без) касса
  печатает товарный чек сама, как кнопка «Печать чека» (тот же `printSale`, сдача, блок книжки,
  скидка по настройкам). Один лист на чек: при включённых обеих настройках не печатать дважды.
- Выключена → как сейчас (`auto_receipt` — только «В сервис» с машиной; QR — всегда).
- Чек без сети (ушёл в очередь) — печатается сам так же, с временным номером (ответ заказчика 03.11.2026).
- Правка чека (`SaleView`, возврат после исправления) — при включённой настройке товарный чек
  печатается и для чека «На вынос».
- Экраны: строка настройки в `OilBookSettings`. Маршруты: `GET/PUT /settings/oil-book` — новое
  поле. Права, уведомления, журнал — без изменений (журнал `settings.oil_book` уже пишет значения).
- Печать без окна — ярлык «Avtodom касса» с `--kiosk-printing` (ADR о печати без окна), не меняется.

## Не входит
- Выбор принтера из программы, печать без ярлыка без окна.
- Автопечать масляной книжки и документов о долге — как сейчас.

## Решено без вопроса
- Ключ в той же настройке `oil_book` — там уже `auto_receipt`, миграция не нужна.
- Отдельный ключ, а не смена смысла `auto_receipt`: у точек, где включено «только сервис»,
  поведение не меняется само.
