# 036 — Филиал «Айкос»: свой товар, свои долги, бесплатные услуги

Статус: сделано (14.11.2026; ответы 1а, 2а, 3а, 4а; в main, не выкачено)

## Зачем
Заказчик 14.11.2026: «всё в одной программе, разные склады»; «долги разные, даже клиент общий — снизу в скобочке можно показать долг другого филиала»; «для юрлица — чтоб смог смотреть по разным филиалам»; «бот и филиалы разные»; «все услуги бесплатно для клиента» (ответ: в Айкос); «оплата для клиента бесплатно, но мастер всё равно может получить что-то». У «Айкос» товар, склад и статистика свои, владелец переключается и смотрит.

Уже было (SPEC-33): свой склад, кассы, смены, расходы, сотрудники, отчёты филиала; переключатель владельца и «Все филиалы»; общие клиенты, машины, книжка, баллы.

## Что сделано (ADR-197, SPEC-33 §5)
1. **Свой список товаров.** Карточка общая (I16); у филиала — флажок «Свой список товаров» (`branches.own_assortment`, «Настройки → Филиалы»; новый филиал на экране — отмечен), у строки филиала — `branch_products.listed`. Новый товар продаётся в филиале, где завели, и во всех филиалах без своего списка (так прежние филиалы работают как раньше). В карточке товара у владельца — «Продаётся в филиалах». Неотмеченный товар не виден в поиске, списках, снимке кассы, ревизии и «заканчивается»; чек, приход, оприходование — 409 (без сети — с причиной владельцу); снять отметку при остатке — 409. Для Айкоса у главного филиала тоже ставится «Свой список товаров».
2. **Долги раздельно.** «Настройки → Касса» → «Принимать долг других филиалов» (выкл по умолчанию — просьба заказчика). Выкл: баланс, лимит, просрочка и погашение клиента — только этого филиала, переплата — аванс здесь; расчётов между филиалами нет. Вкл — SPEC-33 §2.
3. **Показ долга.** Карточка клиента, выбор клиента и строка «В долг» на кассе, окно оплаты долга, «Долги»: долг филиала, ниже — «(в Автодом: N с)». «Все филиалы» у владельца — общий долг.
4. **Кабинет юрлица** — общий долг с разбивкой; переключатель «Все филиалы / …» над «Покупками» и «Актом сверки».
5. **Бот один** (3а): «💳 Мой долг» — общий долг и строкой по каждому филиалу, долг в одном филиале — с названием. Баллы и книжка — общие (SPEC-33), не делятся.
6. **Услуги бесплатно для клиента** — «Настройки → Касса» филиала (выкл по умолчанию): услуги в чеке — 0 с (цена > 0 — 422), мастер получает свою ставку за услугу (`master_fee_tyiyn` не зависит от цены). Процент кассира с 0 с — 0.

## Данные, маршруты, права
- Миграция 0110: `branch_products.listed`, `branches.own_assortment` (по умолчанию — как было).
- `GET|PATCH /products/{id}/branches` (владелец, `op_id`, журнал `product.listed`); `GET /products?unlisted=true` (владелец); `own_assortment` в `POST|PATCH /branches`.
- Карточка клиента: `debts_separate`, `branch_balances[].here`; кабинет: `/client/sales|reconciliation?branch_id=`, `/client/me` → `branches`.
- Настройки кассы филиала: `repay_other_branches`, `services_free` (PUT с `op_id`, журнал). Новых прав и событий ленты нет.

## Не входит
Перемещение товара между филиалами; свой бот у филиала; баллы по филиалам; этикетки не проверяют список филиала; пункты задачи 037.

## Решено без вопроса
- Правило нового товара — через флажок филиала, а не «только где завели»: иначе прежние филиалы без своего списка перестали бы видеть новые товары друг друга (I21).
- Настройка долгов — у каждого филиала своя (принимающий филиал решает, гасит ли он чужие долги).
- Мастеру за бесплатную услугу — его ставка за услугу, как за платную.
