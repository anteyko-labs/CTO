# 047 — Свои услуги у каждого филиала

Статус: утверждено (22.11.2026, владелец: «да»)

## Зачем
Владелец 22.11.2026: «у каждого филиала свои услуги, то есть услуги, которые вчера и сегодня
созданы, — это Айкоса». Сейчас справочник услуг общий (I16, задача 044 отбирает только по виду
машины): Айкос видит услуги Автодома в «Справочниках», Автодом — услуги Айкоса.

## Отступление
I16: «общие — каталог, справочники». Новый ADR: услуги — справочник филиала (у услуги уже есть
`services.branch_id` — филиал, где завели). Каталог товаров, категории, клиенты остаются общими.

## Что меняется
1. «Справочники → Услуги», касса, «Избранное», офлайн-снимок, импорт услуг — только услуги своего
   филиала (`services.branch_id = филиал входа`). Владелец видит услуги того филиала, в который вошёл
   (переключатель филиала, как у остальных экранов).
2. Новая услуга — в филиал, где завели. Название уникально внутри филиала (сейчас — по всей базе):
   в Айкосе может быть своя «ЗАМЕНА МАСЛА В ДВИГАТЕЛЕ».
3. `POST /sales`: услуга чужого филиала — 422 «Услуга другого филиала»; без сети — проводится
   с причиной владельцу (I10).
4. Новый филиал: справочник услуг пустой (галочка «Скопировать услуги из основного» при создании —
   по умолчанию выкл.).
5. Отбор по виду машины (задача 044) остаётся внутри своих услуг.
6. Данные: 13 услуг 01–10.11 — Основной (Автодом), 2 услуги 22.11 — Айкос; так уже записано в
   `services.branch_id`, перенос не нужен.
7. Старые чеки, отчёты, книжка, ставки мастеров — без изменений (услуга в старом чеке читается
   по id, филиал не проверяется).

## Не входит
- Общая услуга для нескольких филиалов (заводится в каждом).

## Затронутые места
`server/src/api/refs.rs:622,873` (список, уникальность), `server/src/api/sales.rs` (проверка
филиала услуги), `server/src/api/offline.rs`, `server/src/api/favorites.rs`,
`server/src/api/branches.rs:190` (`init_branch`), миграция: уникальность названия
`(branch_id, lower(name))`; `docs/sdd/tier0-invariants.md` (I16), `docs/tier-4/spec-33-branches.md`,
ADR.

## Проверка
- Сервер: список услуг Айкоса — только 2 его; Автодома — 13; чек Айкоса с услугой Автодома — 422;
  без сети — с причиной; одинаковое название в двух филиалах — можно, в одном — 409.
- e2e: касса Айкоса показывает только услуги Айкоса.

## Решено без вопроса
- Филиал услуги — тот, где завели (`branch_id` уже есть, переноса не нужно).
