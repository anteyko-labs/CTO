# 041 — Все фильтры в книжке, «может подходить», похожие товары при правке

Статус: утверждено (20.11.2026, владелец: список фильтров «минимум», «при редактировании пусть похожие предлагает из общей базы Автодом/Айкос и там же редактировать»)

## Зачем
Владелец 20.11.2026 прислал список фильтров для книжки: масляный (может быть несколько), воздушный (несколько), топливный (несколько), фильтр коробки (может подходить масляный), топливный грубой очистки — сепаратор, салонный (может подходить воздушный), влагоотделитель, фильтр антифриза, фильтр гидравлической системы. Товар заведён из Excel (Умаг) — при правке нужно видеть похожие из общей базы и сразу править.

## Что меняется
### A. Места фильтров в книжке (дополняет ADR-205, SPEC-32)
1. Новые места книжки (`categories.book_slot`): `gearbox_filter` «Фильтр коробки», `fuel_separator` «Топливный фильтр грубой очистки (сепаратор)», `water_separator` «Влагоотделитель», `coolant_filter` «Фильтр антифриза», `hydraulic_filter` «Фильтр гидравлической системы» — к существующим масляному, воздушному, топливному, салонному.
2. Миграция 0119: категория «ФИЛЬТР АКПП» → `gearbox_filter`; недостающие категории заводятся (kind `filter`) — «СЕПАРАТОРЫ», «ВЛАГООТДЕЛИТЕЛИ», «ФИЛЬТРЫ АНТИФРИЗА», «ГИДРАВЛИЧЕСКИЕ ФИЛЬТРЫ» (если категории с таким именем без учёта регистра нет). Интервалы — пустые (владелец ставит в категории).
3. Любого фильтра в чеке может быть несколько — каждый строкой книжки со своей следующей заменой (как в 040).
4. **«Куда поставили»** у строки фильтра на кассе: по умолчанию место категории; масляный можно поставить как «Фильтр коробки», воздушный — как «Салонный». Выбранное место идёт в книжку и чек.

### B. Похожие товары при правке (дополняет SPEC-03)
5. В карточке товара (правка) — блок «Похожие в базе»: до 10 товаров общей базы (оба филиала) с похожим названием или тем же штрихкодом/артикулом; у каждого — категория, остаток по филиалам, цена. Прямо в строке — сменить категорию и название; «Открыть» — его карточка.
6. «Взять категорию» — одной кнопкой поставить этому товару категорию похожего.
7. Похожесть — по словам названия (без регистра, без «фильтр», знаков), числам/артикулам и штрихкоду; на сервере `GET /products/{id}/similar`. Права — как у правки товара (`products`).

## Проверка
- Сервер: чек с масляным фильтром как «Фильтр коробки» — в книжке место `gearbox_filter`; 3 фильтра одной категории — 3 строки; миграция не дублирует категории; `similar` находит по артикулу и словам, не находит себя, без права — 403.
- Веб: юнит на выбор места; e2e — точечно (касса и карточка товара), полный e2e — один раз перед выкатом.

## Решено без вопроса
- «Может подходить» — только две пары из списка владельца (масляный → коробки, воздушный → салонный).
- Слияние дублей товаров не входит: только показ и правка.
