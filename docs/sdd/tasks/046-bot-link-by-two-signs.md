# 046 — Подключение клиента в боте по двум признакам

Статус: утверждено (22.11.2026, владелец: „в ТГ пусть клиент подключается не только по телефону, но и по ИНН, ФИО, номеру машины“; безопасность — „два признака сразу“)

## Зачем
Не у всех клиентов в карточке актуальный телефон; подключиться должно быть можно и без него.

## Отступление
ADR-051/063 — подключение только своим номером. ADR-212 добавляет второй путь.

## Что меняется
- Кнопка «🔎 Найти себя по ИНН, ФИО или госномеру» рядом с «📱 Поделиться номером» (`Keys::Contact`).
- `server/src/api/bot_signs.rs`: ожидание (`bot_sign_wait`, 15 мин), разбор сообщения, поиск ровно одной
  карточки с ≥ 2 совпавшими признаками, лимит 5 неудач в сутки (`bot_sign_tries`), миграция 0126.
- Привязка — `telegram::link_party` (общая с кодом из ссылки), журнал `telegram.customer_link`, `via = "signs"`.
- SPEC-18 — раздел «Дополнено задачей 046».

## Не меняется
Подключение номером и ссылкой, отвязка при смене номера/отключении карточки, уведомления и лента.

## Приёмка (server/tests/bot_signs.rs)
- два признака одной карточки → подключён; один признак → отказ;
- признаки разных карточек или две одинаковые карточки → отказ;
- после 5 неудач за сутки — отказ даже с верными признаками; другой чат не задет.
