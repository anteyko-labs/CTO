# 016 — Свои строки (категории) книжки

Статус: сделано

## Зачем
Заказчик: «в категориях их видно и там список — сделай возможность создать, сейчас только выбрать».
В окне «Запись книжки» строку «Что меняли» можно выбрать только из встроенных (масло, фильтры, антифриз…, «Прочие работы»).
Работы вне списка (свечи, ремень ГРМ, жидкость ГУР) уходят в «Прочие работы» и в книжке не различаются.

## Что меняется
1. В списке «Что меняли» (окно «Запись книжки») последний пункт — «+ Новая строка…». Выбор открывает поля «Название»,
   «Интервал, км», «Интервал, дней» (оба необязательны) и кнопку «Создать»;
   созданная строка сразу выбрана в этой строке записи и появляется в списке у всех машин точки.
2. Своя строка хранится как слот `other` + ссылка на свою строку и показывается своим названием в книжке, печати и боте.
   Срок следующей замены — пробег + свой интервал км (в книжке) и дата + свой интервал дней (только для бота, ADR-182);
   без интервала — нет срока и напоминания. Бот напоминает по своей строке её названием.
3. Встроенные строки не меняются и не удаляются. Свои — переименовать, сменить интервал, скрыть в «Настройках → Книжка»
   (скрытая пропадает из списка выбора, старые записи сохраняют название).
4. Название: 2–40 символов, без повтора (без учёта регистра) со встроенными и своими строками точки.
5. Журнал: создание, переименование, скрытие — запись в журнале действий.

Маршруты:
- `GET /book-slots` — свои строки точки, со скрытыми (`{id, name, interval_km, interval_days, hidden}`); встроенные — на клиенте.
- `POST /book-slots` `{name, interval_km?, interval_days?}` → тот же объект; `PATCH /book-slots/{id}` `{name?, interval_km?, interval_days?, hidden?}`.
- `PATCH /oil-changes/{id}` (задача 013): у строки появляется `custom_slot_id` (необязательно).

Данные / миграция `0101_book_custom_slots.sql`:
- таблица `book_custom_slots(id, branch_id, name, interval_km, interval_days, hidden, created_at)`
  (интервалы — те же пределы, что в 0064: 500–200000 км, 1–1095 дней), уникальность `(branch_id, lower(name))`;
- `oil_change_items.custom_slot_id` → `book_custom_slots(id)`, допустим только при `slot = 'other'` (CHECK).
- CHECK встроенных слотов (0064) не трогаем.

Права: создавать из окна записи — тот, кто может править запись (задача 013); правка и скрытие в настройках — владелец/админ.
Уведомления: бот называет строку её названием, если по ней есть напоминание.

## Не входит
- Свои строки в категориях товаров / услуг (`categories.book_slot`, `services.book_slot`) и на кассе при продаже — только книжка.
- Удаление строки, слияние строк.

## Решено без вопроса
- Своя строка = `other` + `custom_slot_id`: встроенные CHECK и правила срока (ADR-117, ADR-144) не меняются.
- Строки — на точку (`branch_id`), как остальные справочники.
- Срок своей строки считает сервер по её интервалу (как `target_auto`, ADR-144), не по правилам «Прочих работ».
- Новая таблица — расширение без новой библиотеки; ADR — фиксирует модель «`other` + название».

## Ответы заказчика
1. б — своя строка напоминает в боте, интервал км/дни задаётся при создании.
2. а — создавать из окна записи могут все, кто правит записи.
3. а — только книжка.
