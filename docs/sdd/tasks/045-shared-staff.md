# 045 — Общие сотрудники филиалов

Статус: утверждено (21.11.2026, владелец: „сотрудники у 2 филиалах одни и те же“)

## Зачем
В обоих филиалах работают одни и те же люди: кассира и мастера нужно выбирать в чеке любого
филиала, терминал лица каждого филиала должен узнавать всех.

## Отступление
ADR-108/SPEC-33 §1: «работники у каждого филиала свои». ADR-211 уточняет — по умолчанию общие.

## Что меняется
- Миграция 0125: `branches.own_staff boolean not null default false`, функция `staff_branch_ids(uuid)`.
- Чтение и выбор сотрудников (список, касса, без сети, смена, приход, бот, выходные, табель,
  Face ID, PIN, права кассира) — `branch_id = any(staff_branch_ids($n))`. Создание — в текущий филиал.
- Face ID: поиск номера по группе (сначала свои), уникальность номера — по группе;
  рабочий день — с филиалом терминала.
- Веб: флажок «Свои сотрудники» в «Настройки → Филиалы»; колонка «Филиал» в списке сотрудников.

## Не меняется
Начисления и зарплата — по филиалу чека/смены; деньги и кассы; расчёт зарплаты и отчёты по
сотрудникам — по своему филиалу.
