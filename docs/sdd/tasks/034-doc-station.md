# 034 — Акт сверки, долговые и крупные документы — на принтер HP (станция документов)

Статус: сделано (05.11.2026; заказчик: «акт сверки и крупные доки как и долги должны с большого принтера hp печататься… он в чековом принтере 58 по дефолту печатает, срочно»)

## Зачем
Окно кассы печатает без диалога (`--kiosk-printing`) на один принтер своего профиля — чековый POS58.
Документы A4 выходили на ленте 58 мм. На моноблоке есть очередь HP LaserJet 1018 (USB003).

## Что меняется
- Очередь печати получает вид станции `doc`: `/label-station?size=doc` — своё окно Chrome на моноблоке,
  свой профиль, принтер HP. Берёт только задания `doc` и печатает их в изолированном фрейме.
- `POST /label-jobs/doc {op_id, title, html}` → `{id, status, station_online}`; без права, как этикетки;
  HTML ≤ 4 МБ, пустой — 422; повтор `op_id` — то же задание. Журнал — `label_job.create`, только название.
- HTML документа стирается после печати, ошибки и устаревания. Ожидание в очереди — не дольше 2 мин.
- Какие документы: всё, что идёт через `printHtml` (акт сверки, документы о долге, договоры), лист
  остатков, отчёт о прибыли, отчёт смены (страницей). Чеки, книжка, этикетки и отчёт смены на ленте — без изменений.
- Маршрут — по устройству: окно кассы открыто ярлыком с `?docs=station`, флаг в браузере
  (`?docs=local` снимает). Без флага печать как раньше: телефон и ноутбук владельца не печатают в точке,
  кабинет юрлица не затронут.
- С флагом станция не в сети или нет связи — документ не печатается, касса говорит почему.
- `deploy/windows/install-doc-station.ps1`: ярлык «Avtodom docs», профиль с принтером HP, `?docs=station` в ярлыке кассы.
