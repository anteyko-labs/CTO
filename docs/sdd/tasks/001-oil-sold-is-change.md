# 001 — проданное масло в чеке «В сервис» — замена, доливка — на вынос

Статус: сделано (28.10.2026)

## Зачем
Чек № 17 (Camry 08270AUK, 28.10.2026): ATF Totachi Dexron III 4 л не попал в книжку — по ADR-117 жидкость без услуги своей строки считается доливкой. Заказчик 28.10.2026: «замена масла нужна, а где доливка написано — не нужна»; «сделай, чтобы доливку можно было на вынос забрать».

## Что меняется (поведение)
1. Чек «В сервис»: товар-масло (строка книжки `oil` — моторное, `gear_oil` — трансмиссионное/ATF) — это замена, даже если услуги той же строки в чеке нет. Пишется строкой книжки с целью следующей замены.
2. Цель для такой строки: пробег сейчас + интервал (свой интервал машины → категория → строка по умолчанию, как `interval_days`/`category_interval` сейчас); дата — по дням так же. Кассир видит строку в «Следующей замене», может исправить или очистить («не напоминать»).
3. Доливка — не замена:
   - чек «На вынос» — книжки нет (как сейчас, ADR-118);
   - в чеке «В сервис» есть услуга-доливка (флажок «Доливка — на вынос» или слово «долив» в названии) — масло той же строки в книжку не пишется. Доливка КПП (сейчас строка «прочее») относится к `gear_oil`, «Доливка масла» (двигатель) — к `oil`; связь — по названию: «кпп», «акпп», «коробк», «atf» → `gear_oil`, иначе `oil`.
4. «Доливку на вынос забрать»: продажа масла в чеке «На вынос» уже есть (ADR-118); проверить, что она работает для любого масла (в т.ч. ATF) без клиента и книжки. «Это замена масла?» на вынос — без изменений.
5. Антифриз и тормозная жидкость — без изменений (ADR-117: только с услугой своей строки или целью кассира).
6. Фильтры с маслом двигателя (ADR-117) — как сейчас; строка масла по товару тоже даёт им цель масла.
7. Прежние записи книжки (в т.ч. чек № 17) не меняются (I4).

## Экраны
- Касса, «Следующая замена»: строка по товару-маслу без услуги своей строки (подпись — метка строки, «Масло в коробке: Totachi ATF Dexron III»). Правки такой строки переживают изменение услуг, «Исправить» и «Вернуть» (`pruneNext`, `nextFromDraft`, `Cashier.tsx:~1388`).
- Подсказка «Это замена?» (`oilChangeHint`) остаётся — напоминает добавить услугу замены (ставка мастеру); показывается и для `gear_oil`.

## Маршруты и данные
- Тело чека, `next_change`: строка по товару — `slot` без `service_id`; сервер принимает цель по `slot` только для `oil`/`gear_oil`, только если такой товар есть в чеке и нет доливки этой строки. Остальные цели — по услуге, как ADR-131.
- Миграция не нужна. Новых прав и уведомлений нет.

## Не входит
- Пересчёт прошлых чеков; антифриз/тормозная по товару; изменение «+ ещё строку» (товары там не предлагаются, ADR-131).

- `server/tests/oil_book*.rs` (или новый `oil_sold.rs`):
  - ATF без услуги АКПП + «Замена со своим маслом» → строки `oil` и `gear_oil`, у `gear_oil` цель по интервалу категории (случай чека № 17);
  - моторное масло без услуги → строка `oil` с целью, фильтры получают цель масла;

## Решено без вопроса
- Объём не важен (заказчик 28.10.2026: «доливка это доливка сколько бы не было литров»): доливку определяет только услуга-доливка или чек «На вынос», порога объёма нет.
- Услуга замены той же строки и доливка в одном чеке — замена пишется (`flow.rs:11360`); доливка гасит только замену «по товару».
- Сервер пишет строку oil/gear_oil по товару и без цели от кассы (старая/офлайн-касса): цель — по интервалу.
- Обновить тесты под новое поведение: `oil_book_check.rs:478`, `web/e2e/next-change-receipt.spec.ts:289`, `nextChange.test.ts:191`.
- Интервал — существующая цепочка (машина → категория → по умолчанию), новой настройки нет.
- Связь доливки со строкой — по названию услуги (как ADR-117 для «мост/редуктор»).

- ADR-131 сохраняется (ответ заказчика 28.10.2026 — «да»): в чеке есть услуга «прочее» со словом «ГУР», «мост», «редуктор», «раздатка» — ATF как замену масла коробки в книжку не пишем; тест на это — в серверный набор.
