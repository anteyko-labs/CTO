# 006 — печать этикеток на складском принтере с телефона («Станция этикеток»)

Статус: сделано (02.11.2026; утверждено с ответами по умолчанию 1а, 2б; ветка feat-006-label-station)

## Зачем
Владелец 02.11.2026: «тут есть икспринтер на складе — вот новый товар, штрих-код должен тут выходить, если с телефона там напечатать». Сейчас этикетка печатается окном браузера на том же устройстве (SPEC-02 «Этикетки»), с телефона — некуда.

## Что меняется
- **Н1 Очередь печати этикеток.** Таблица `label_jobs` (`id`, `branch_id`, `op_id` уникальный, `items` JSONB `[{product_id, copies}]`, `status` `queued|printing|done|failed`, `error`, `created_by`, `created_at`, `taken_at`, `done_at`, `station_id`). Строки товара на этикетке берутся при печати с сервера (название, цена, код — как `printLabels` сейчас). Копий в задании ≤ 500 (иначе 422). Задание старше 24 ч в `queued` — `failed` «устарело».
- **Н2 Отправка.** Везде, где сейчас «Этикетки»/«Печать этикеток» (`Products`, карточка нового товара, `ReceiptNew`, `ReceiptView`, `StockInView`), — выбор «Здесь» / «На складе». `POST /label-jobs {op_id, items}` → `{id, status}`; повтор op_id — то же задание (I8). Без сети — кнопка «На складе» недоступна с подсказкой (I9 — только касса работает без сети).
- **Н3 Станция.** Страница `/label-station` (вход любым администратором филиала, отдельное право не нужно — этикетки без права, SPEC-01). Раз в 3 с: `POST /label-jobs/take` → одно задание `queued` → `printing` (`SELECT … FOR UPDATE SKIP LOCKED`, две станции не берут одно), печатает `labelsHtml` (текущие `labels` филиала) через скрытый iframe; Chrome с `--kiosk-printing` печатает на принтер по умолчанию без окна. Затем `POST /label-jobs/{id}/done` или `/failed {error}`. Задание в `printing` дольше 2 мин — снова `queued` (станция перезагрузилась). Экран станции: «Принтер: готов», последние 20 заданий (кто, что, сколько, статус), кнопка «Пробная этикетка». Станция шлёт отметку «жив» с каждым запросом (`label_stations.last_seen`).
- **Н4 Статус на телефоне.** После «На складе» — плашка «В очереди → Печатается → Напечатано (N этикеток)»; `GET /label-jobs/{id}` раз в 2 с до итога, не дольше 2 мин. Станция не отмечалась больше 30 с — сразу «Склад не в сети: этикетки напечатаются, когда станция включится» (задание остаётся). `failed` — текст ошибки и «Повторить».
- **Н5 Настройка (I21).** «Настройки → Этикетки»: «Кнопка по умолчанию на телефоне» — «Здесь» / «На складе» (ключ `labels.remote_default`, по умолчанию «На складе» — прямая просьба). Журнал `settings.labels` как сейчас.
- **Н6 Склад: ПК `avtodom-sklad`.** Ярлык Chrome `--app=https://oilprime.org/label-station --kiosk-printing` в Public Desktop и автозагрузке; Xprinter XP-T371U — принтер по умолчанию; убрать с USB002 лишнюю очередь RONGTA (общий порт); размер этикетки в «Настройки → Этикетки» под рулон Xprinter. Скрипт `deploy/windows/install-label-station.ps1` (латиница в имени ярлыка, см. хвост install-cert.ps1).
- Журнал: `label_job.create` (кто, сколько), без журнала на take/done (служебное).

## Не входит
Прямая печать TSPL/RAW без драйвера; несколько складов/станций с выбором принтера; печать чеков через станцию; уведомления в Телеграм о печати.

## Проверка
- `server/tests/label_jobs.rs`: создание и повтор op_id; 422 при > 500 копий; take выдаёт задание одной станции из двух (параллельно); чужой филиал не видит и не берёт (I16); `printing` > 2 мин возвращается в очередь; устаревание 24 ч; `last_seen` станции и признак «не в сети».
- `web/src/lib/labelJob.test.ts`: переход статусов плашки, «не в сети» по `last_seen`, остановка опроса.
- e2e `label-station.spec.ts`: два контекста — «телефон» (360 px) шлёт «На складе» из карточки товара, «станция» забирает и отмечает done (печать подменена), на телефоне «Напечатано»; станция закрыта → «Склад не в сети».
- Вручную на складе: пробная этикетка с телефона выходит на Xprinter без окна.

## Решено без вопроса
Через страницу в Chrome, а не отдельная программа — без нового сервиса и библиотек (ADR не про новый сервис, а про очередь); печать — тем же `labelsHtml`, что и сейчас; право не вводится (этикетки без права); номер ADR-177, миграция 0097.

## Вопросы
1. Кнопка на телефоне по умолчанию: а) «На складе» (предложено); б) «Здесь»; в) всегда спрашивать.
2. С компьютера кассы (моноблок) этикетки печатать: а) тоже на склад по умолчанию; б) здесь, как сейчас (предложено — у кассы свой принтер чеков, не этикеток).
