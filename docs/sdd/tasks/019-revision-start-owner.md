# 019. Ревизию начинает только владелец

Статус: сделано (03.11.2026; ответ 1а; в main, не выкачено)

## Зачем
Заказчик: «сделай чтобы ревизию мог начать только владелец».
Сейчас новый черновик заводит любой администратор с правом `revision` (`server/src/api/revisions.rs:412`, SPEC-15 §47), в том числе «Сканер товаров» с включённым пересчётом сам открывает ревизию «весь склад» (`web/src/pages/ProductIntake.tsx:276`). Провести ревизию и так может только владелец (`revisions.rs:1087`).

## Что меняется
1. `POST /revisions` — новый черновик заводит только владелец. Администратор (и личный вход сотрудника):
   - открыт подходящий черновик (тот же охват или «весь склад») — получает его, как сейчас («присоединиться»);
   - открыта ревизия другой категории — прежний 409 «Идёт ревизия «…» — закончите или присоединитесь»;
   - черновика нет — 403 «Ревизию начинает владелец».
2. Пересчёт в начатой ревизии (`PUT …/lines`, `DELETE …/lines/{product_id}`, `new-product`) — без изменений: администратор с правом `revision` считает.
3. Отмена черновика (`POST /revisions/{id}/cancel`) — только владелец (ответ 1а); администратор — 403 «Отменить ревизию может только владелец». Кнопки «Отменить» у администратора нет.
4. Экран «Ревизия» (`web/src/pages/Revision.tsx:1612`, `:1709`): у администратора без открытого черновика кнопки «Начать ревизию» / «Начать первую ревизию» нет — вместо неё «Ревизию начинает владелец. Когда начнёт — она появится здесь, откройте её и считайте». Есть открытый черновик — кнопка «Присоединиться к ревизии № N». У владельца — как сейчас.
5. «Сканер товаров» (`ProductIntake.tsx:276`): у администратора нет черновика «весь склад» — переключатель «Пересчёт (ревизия)» выключен и недоступен с подписью «Ревизию начинает владелец»; товар заводится и коды привязываются без пересчёта. Черновик есть — пересчёт пишется в него, как сейчас.
6. Подсказка права `revision` (`web/src/lib/permissions.ts:62`): «Пересчёт товара в ревизии, которую начал владелец; начинает и проводит — владелец». Ключ, подпись, группа, «по умолчанию» — без изменений (миграции нет).
7. Бот, уведомления, данные — без изменений.

## Не входит
- Проведение ревизии (уже только владелец), норма расхождения, очередь сканов.
- Новое право «Начинать ревизию» — не заводим (заказчик сказал «только владелец»; при желании — отдельной задачей).

## Решено без вопроса
- «Начать» = завести новый черновик; присоединиться к уже начатой администратор может — иначе пересчитывать некому.
- Сервер проверяет сам (I12): скрытой кнопки мало.
- Право `revision` остаётся и означает «считать в ревизии»; новое право не заводим.
