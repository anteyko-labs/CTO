# 013 — книжка: следующая замена только по пробегу, правка строки

Статус: сделано (02.11.2026; ответы владельца: дат нет нигде, кроме напоминаний; править может владелец и администратор с правом «Клиенты»; напоминания — по сроку)

## Зачем
Владелец 02.11.2026: «сервисная книжка — убери упоминание дат, типа след. замена какого числа, только пробег оставь; проверь, что с заменой масла идут и фильтры; строку в книжке не могу редачить».

## Что меняется
1. **Без дат следующей замены** (экран книжки `OilBook.tsx`, печать `oilBookPrint.ts`, чек `salePrint.ts`, Excel):
   - «Следующая замена» — только «на 93 000 км». Если пробега нет — «—», а не «по сроку до 15.12.2026» (`oilBook.ts::slotNextText`);
   - интервал — «каждые 8 000 км», без «или 31 дн.»;
   - «пора менять» по дате убрать;
   - подсказка на кассе — без «пора менять» по дате;
   - в Excel убрать столбцы «Следующая, дата» и «Интервал, дней»;
   - поле дней в окне «Интервал» — «Напоминать клиенту через, дней» (только для бота).
   - Дата самой замены в истории («02.11.2026 · 85 000 км») остаётся: это когда меняли, а не когда менять.
2. **Фильтры с маслом** — проверено, правок нет: фильтры из того же чека ложатся в книжку на пробег масла (`server/tests/oil_book_check.rs`, 18/18).
3. **Правка строки книжки:** у каждой записи вместо одной кнопки «Пробег» — «Изменить»: окно (без даты) с пробегом, строками по видам (масло, масляный/воздушный/салонный фильтр, прочее — текстом) и комментарием. `PATCH /oil-changes/{id}` принимает `lines` (`index` — строка записи, без него — новая, неназванная удаляется; без строк — 422). Было → стало — в журнал `vehicle.oil_edit`. Чек не меняется, цель следующей замены у правленой строки остаётся. Правка — у всех записей (как прежняя «Пробег»), право «Клиенты и машины».

## Не входит
Правка суммы и товаров чека: это «Исправить» у чека.
