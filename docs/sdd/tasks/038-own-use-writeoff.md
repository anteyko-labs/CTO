# 038 — Свой товар на нужды магазина из окна мелкого расхода

Статус: сделано (16.11.2026; ответы 1а, 2б, 3в; в main, не выкачено)

## Зачем
Заказчик 16.11.2026: «на кассе к мелкому расходу добавить ещё — товар, который они расходуют, просто как расход магазина» (выбран вариант «списать свой товар»). Раньше такой товар уходил недостачей в ревизии: не видно, куда он делся, и прибыль дня о расходе не знала.

## Что сделано (ADR-198, SPEC-06 и SPEC-08 — «Дополнено задачей 038»)
1. **Окно «Мелкий расход из кассы»** — вкладки «Деньги из кассы» (как раньше) и «Свой товар». На вкладке «Свой товар»: поиск товара (сканер, название), количество в единице товара (шт, л, кг, м — I24), комментарий, кнопка «Списать».
2. **Проведение** — одна транзакция (I7). Движение склада `own_use` по средней себестоимости, без стоимости остатка — по последней закупке (ADR-070, как брак). Касса и смена не участвуют. Больше остатка — 409, товар не своего филиала — 409, повтор `op_id` — тот же ответ (I8). Журнал `stock.own_use`.
3. **Право** — «Расходы», как у мелкого расхода (1а). Себестоимость в ответе видит только владелец.
4. **Прибыль** — отдельная строка «Товар на нужды магазина» (2б) по дню записи, в группе «Списание и брак» с документами. Та же строка — в таблице по дням (колонка «Брак, возвраты, нужды»), в прибыли смены, в итоге дня бота и в ответах помощника. В «Расходах» списаний нет.
5. **Сторно** — `POST /own-use/{id}/reverse`, причина обязательна. Товар возвращается той же стоимостью, строка прибыли гасится. Владелец сторнирует любое списание, администратор — своё и только за сегодня.
6. **Бот** — сообщений нет (3в).

## Данные, маршруты
- Миграция 0111: `own_use_writeoffs` (номер, товар, кол-во, себестоимость, комментарий, `reversal_of`; неизменяемая, сторно — одно).
- `POST /own-use`, `POST /own-use/{id}/reverse`, `GET /own-use?from&to` (администратору — за 7 дней); `totals.own_use_tyiyn`, `days[].own_use_tyiyn`, `detail.own_use`.

## Не входит
Несколько товаров одним документом (списание по одному товару); экран списка списаний (видно в «Прибыли и убытках»); списание по цене продажи; брак (SPEC-25).
