# 044 — Услуги для легковых и грузовых

Статус: сделано

## Зачем
Заказчик: «все услуги автодома для легковых; если выбран грузовые — должны услуги для
грузовых показывать; пока выключи легковые в Айкосе и грузовые в Автодоме».
На чеке уже есть «Грузовая / Легковая» (задача 040 A, ADR-205), но это только отметка:
список услуг на кассе один для всех.

## Отступление
ADR-205: «цены и состав не меняются». Новый ADR уточняет: вид машины чека отбирает услуги.
Справочник услуг остаётся общим (I16 не нарушается).

## Что меняется
- У услуги — вид машины `vehicle_kind`: `car` (легковая) или `truck` (грузовая).
  Миграция: столбец `services.vehicle_kind text not null default 'car' check in (car, truck)`;
  все имеющиеся услуги — `car`.
- «Справочники → Услуги» (`web/src/pages/Services.tsx`): столбец и выбор «Легковая / Грузовая»
  при создании и правке; фильтр по виду; импорт — колонка «Вид» (нет — легковая).
- Касса: в списке услуг и плитках «Избранное» только услуги вида машины чека; переключили
  «Грузовая ↔ Легковая» — список меняется. Услуги другого вида уже в чеке — предупреждение
  «Услуга для легковых/грузовых» и удаление одной кнопкой.
- Настройка кассы филиала (ключ `cashier`, только владелец, журнал I5):
  «Услуги легковых» и «Услуги грузовых» (вкл/выкл, по умолчанию вкл — I21).
  Выключенный вид не показывается на кассе филиала и не принимается в чек.
  Миграцией: Айкос — легковые выкл., Автодом — грузовые выкл. (просьба владельца 21.11.2026).
  Если оба вида выключены — 422 «Включите хотя бы один вид услуг».
- Если выключен вид, который стоит по умолчанию у чека, — кнопка «Грузовая / Легковая»
  оставляет только включённый вид.
- `POST /sales`: услуга не того вида, что чек, или выключенного в филиале вида — 422
  «Услуга для грузовых/легковых»; без сети — проводится с причиной владельцу (I10).
- Офлайн-снимок (`server/src/api/offline.rs:249`) отдаёт `vehicle_kind` услуги; касса без сети
  отбирает так же.
- Старые чеки, отчёты, книжка, бот — без изменений.

## Не входит
- Разные цены одной услуги для легковых и грузовых (заводятся две услуги).
- Свой справочник услуг у филиала.

## Решено без вопроса
- Справочник общий: одна услуга — один вид; вид не меняет цену и ставку мастера.
- Настройка по умолчанию «оба включены», для двух филиалов — по просьбе владельца.
