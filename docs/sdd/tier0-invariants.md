# Tier 0 — инварианты (Spec-as-Source)

Сжатая выжимка `docs/tier-0/invariants.md` (там полный текст и источник). Нарушить нельзя; отступление — только новой записью ADR в `docs/tier-5/decisions.md` (записи только добавляются).

## Деньги и количества
- I1. Только целые: деньги — тыйыны BIGINT, объёмы — мл, штуки — штуки. Float в расчётах запрещён.
- I2. Округление в одном месте; перевод в сомы/литры — только при показе. Мили → км только `domain::mileage` / `lib/mileage.ts`.
- I3. Себестоимость — средневзвешенная, пересчёт при приходе; в строке чека фиксируется в момент продажи и не меняется.

## Неизменяемость и атомарность
- I4. Проведённое (чек, приход, выплата, расход, перелив, долг) не правится и не удаляется — только сторно со ссылкой на исходное.
- I5. Журнал действий (кто, когда, устройство) — только пополняется.
- I6. Остаток товара и баланс кассы = сумма движений; расхождение — ошибка.
- I7. Одна операция — одна транзакция (товар, деньги, мастер, долг — всё или ничего).
- I8. Идемпотентность по `op_id` (UUID с клиента): повтор возвращает ту же запись, не дубль.

## Офлайн
- I9. Без сети работает только касса (продажа, оплата, поиск); операции копятся и уходят при связи.
- I10. Сервер решает окончательно: минус после синхронизации проводится с пометкой владельцу; состоявшаяся продажа не отменяется.
- I11. Прибыль, цены, перелив, выплаты, изменение оплаты — только при связи.

## Доступ
- I12. Права проверяет сервер; скрытая кнопка — не защита.
- I13. Прибыль, маржа, себестоимость, сводные доходы — только владельцу; администратору сервер их не отдаёт.
- I14. Сторно и правка проведённого — владелец, если ADR явно не разрешает иное (перелив с правом — ADR-082; цена литра и отмена перелива — только владелец).
- I15. Мастера и кассиры — без входа (записи справочника, PIN для смены и приёмки); действие привязано к вошедшему владельцу или администратору.

## Филиалы и учёт
- I16. Всё содержит `branch_id`; филиал видит только себя, владелец — все; общие — каталог, справочники, клиенты.
- I17. Один учёт, без режимов выборочного показа оборота.

## Код и процесс
- I18. Rust: без `unwrap`/`expect`/`panic!` вне тестов.
- I19. Секретов в репозитории нет.
- I20. Функция без утверждённой спецификации (`docs/tier-4/spec-*.md` или `docs/sdd/tasks/NNN-*.md` со статусом «утверждено») не реализуется.
