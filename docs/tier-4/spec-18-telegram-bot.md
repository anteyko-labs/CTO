# SPEC-18. Телеграм-бот: владелец и клиенты

## Задача

Владелец получает важные события точки в Телеграм, не открывая систему, и по команде видит сводку дня. Обычный бот: только сообщения из учёта и команды, без ответов на произвольный текст (ADR-050). Бот ничего не проводит — это только просмотр.

## Работа

- Ключ бота от @BotFather задаётся на сервере переменной `TELEGRAM_BOT_TOKEN`. Без ключа бот выключен, остальная система работает как прежде.
- Сервер сам опрашивает Телеграм (`getUpdates`, long polling) и отправляет сообщения (`sendMessage`) — входящие запросы и туннель для бота не нужны. Без интернета циклы ждут и пробуют снова; события не теряются: курсор журнала двигается только после отправки.
- Привязка: владелец в «Настройки → Телеграм» получает шестизначный код на 15 минут и отправляет боту `/start 123456`. Чат привязывается к владельцу; код одноразовый. Команды владельца другим чатам не отвечают.
- Уведомления владельцу — всё, что происходит на точке: события экрана «Уведомления» (SPEC-13) и текущая работа — каждый чек (номер, сумма, способы оплаты, кассир, мастер, клиент и машина), открытие и закрытие смены с итогом пересчёта, приходы, расходы и их сторно, погашения долгов, выплаты, оклады, премии и удержания, внесения и изъятия, переводы денег, приём аккумуляторов, переливы, объединение карточек. После закрытия смены следом приходит сводка дня. При первом запуске прошлое пачкой не присылается.
- Кнопки внизу чата (постоянная клавиатура Телеграма), их текст работает и как команда. У владельца: «📊 Сегодня» (`/сегодня`) — чеки, выручка, валовая и чистая прибыль, деньги в кассах; «💵 Смена» (`/смена`) — открытая смена, кассир, сколько должно быть в кассе, оплаты по способам; «📒 Долги» (`/долги`) — кто сколько должен. Прибыль показывается только по команде владельца.

## Клиенты (ADR-051)

- Любой, кто не владелец, пишет боту — бот просит кнопкой «Поделиться номером». Принимается только свой номер (контакт того, кто пишет); чат привязывается к покупателю, у которого в карточке тот же телефон (сравниваются последние 9 цифр).
- Подключённому клиенту на любое сообщение бот отвечает его масляной книжкой (SPEC-16): по каждой машине — дата и пробег последней замены, масло, фильтр, следующая замена по пробегу и дате. Деньги, долги и сводки точки клиенту не показываются.
- Напоминание о замене — за 7 дней и за 1 день до даты следующей замены, каждое один раз (`oil_reminders`). Срок по умолчанию — 31 день после замены, в карточке машины меняется.
- Кнопки клиента: «🚗 Мои машины» — книжка, «⭐ Баллы» — баллы (SPEC-19), «🚪 Отключиться» — с подтверждением «Да, отключиться» / «Назад» (или `/стоп`). Вернуться — снова «📱 Поделиться номером». Не подключённому показывается только кнопка номера.

## Данные

```
telegram_links (chat_id, user_id unique, branch_id, linked_at)
telegram_codes (code, user_id, expires_at)
bot_state (key, value)   -- курсор журнала
telegram_customers (chat_id, party_id, phone, linked_at)
oil_reminders (vehicle_id, due_date, days_before, sent_at)
```

## API

- `GET /settings/telegram` → включён ли бот, привязан ли чат.
- `POST /settings/telegram/code` → код привязки. `DELETE /settings/telegram` — отвязать. Только владелец.

## Критерии приёмки

- [x] Без ключа бот выключен, экран настроек об этом говорит.
- [x] Код привязывает чат владельца один раз; чужой чат получает только подсказку.
- [x] Команды отвечают сводкой из учёта.
- [x] Новое событие журнала уходит в привязанный чат, старое при первом запуске — нет.
- [x] Клиент подключается только своим номером и видит только свои машины; номер не из базы — подсказка.
- [x] Напоминания за 7 и за 1 день уходят по одному разу; после отключения — не уходят.
- [x] Кнопки владельца и клиента отвечают так же, как команды; отключение — только после подтверждения.
