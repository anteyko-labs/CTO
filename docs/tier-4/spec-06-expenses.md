# SPEC-06. Операционные расходы

## Задача

Расходы по статьям с комментарием; расход из кассы уменьшает наличные; расходы уменьшают прибыль своего дня (BLUEPRINT §3.6, ADR-023).

## Данные

```
expense_articles (id, branch_id, name, owner_only, active)
expenses (id, branch_id, number, article_id, amount_tyiyn, source account | outside,
          account_id?, expense_date, comment, reversal_of,
          user_id, device_id, created_at)                         -- неизменяемая
```

- `amount_tyiyn` > 0 у расхода, < 0 у сторно.
- `source = account` — деньги ушли из кассы системы: наличными из «Кассы» или безналично со «Счёта» (`account_id`, по умолчанию касса смены). `source = outside` — оплачено не деньгами точки, например владелец заплатил своими; кассы не затрагивает, прибыль уменьшает.
- `expense_date` — день, к которому относится расход в отчёте о прибыли. По умолчанию сегодня (Asia/Bishkek).
- `owner_only` — статья видна и доступна только владельцу.

Статьи миграцией: «На развитие», «Хозтовары», «Налоги», «Личные расходы» (`owner_only`), «Прочее». Остальные статьи владелец добавляет сам.

Личные расходы владельца уменьшают и кассу, и прибыль магазина, как любая другая статья: один учёт, отдельного признака у статьи нет (ADR-023).

Статей «Зарплата» и «Проценты работникам» здесь нет: оплата сотрудников проходит начислениями и выплатами (SPEC-07). Иначе одни и те же деньги уменьшили бы прибыль дважды.

## Проведение

`POST /expenses {op_id, article_id, amount_tyiyn, source, account_id?, expense_date?, comment?}`

```
в run_operation:
  статья активна; amount > 0
  если статья «Прочее» — comment обязателен
  если source = account:
     lock cash_accounts; amount ≤ баланс кассы (422)
     для кассы типа register нужна открытая смена (409); для счёта смена не нужна
     cash_movement(expense, −amount, shift_id, doc = expense)
  expense = insert (number = next(expense_seq))
  audit expense.post
```

## Сторно

`POST /expenses/{id}/reverse {op_id, comment}`

- Новая строка `expenses` с `reversal_of`, суммой со знаком минус, той же статьёй и тем же `expense_date`: в отчёте за день расход и сторно взаимно гасятся.
- Для `source = account` — движение `reversal` на +amount в ту же кассу; для кассы смены нужна открытая смена.
- Повторное сторно → 409.

## Чтение

- `GET /expenses?from&to&article_id&source&account_id` → список с итогом по статьям.
- `GET /expense-articles`, `POST /expense-articles`, `PATCH /expense-articles/{id}` (имя, активность, `owner_only`).

## Права

| Действие | Владелец | Администратор |
| --- | --- | --- |
| Расход из кассы смены по обычной статье, за сегодня | да | да |
| Расход со счёта, расход `outside`, задним числом, статьи `owner_only` | да | нет |
| Сторно | любой расход | свой расход из кассы смены, пока она открыта |
| Просмотр | все | только расходы из кассы смены за 7 дней |
| Статьи: создание и правка | да | нет |

Администратор не видит расходов со счёта, расходов `outside` и статей `owner_only` — это сводные расходы магазина (инвариант 13).

## Клиент

- Экран «Расходы»: кнопка «Новый расход» — статья (крупные кнопки частых статей), сумма, откуда платим (касса, счёт, «не из денег точки» — последние два только владельцу), дата (только владельцу), комментарий.
- Мелкий расход администратор проводит прямо с экрана кассы, не уходя из неё: статья, сумма, комментарий. Деньги уходят из кассы сразу, и это видно в разбивке смены (SPEC-05).
- Список за выбранный день или период с итогами по статьям; строка сторно показывается под исходной.
- Расходы из кассы видны в разбивке смены (SPEC-05).

## Критерии приёмки

- [ ] Расход из кассы 300 с уменьшает ожидаемую сумму смены на 300 с.
- [ ] Расход из кассы больше баланса → 422, ничего не записано.
- [ ] Расход со счёта уменьшает остаток счёта и не трогает наличные; расход `outside` не меняет ни одну кассу, но попадает в прибыль дня `expense_date`.
- [ ] Личный расход 5 000 с из кассы: наличных меньше на 5 000 с, чистая прибыль дня меньше на 5 000 с.
- [ ] Администратор: расход со счёта, `outside`, задним числом или по статье `owner_only` → 403.
- [ ] Администратор не получает в списке расходы со счёта, `outside` и статьи `owner_only`.
- [ ] Сторно возвращает наличные в кассу и гасит расход в том же дне отчёта.
- [ ] Повторное сторно → 409; повтор `op_id` не создаёт второй расход.

## Решения для ADR

- ADR-023: состав статей расходов; оплата сотрудников статьёй расхода не проводится; личные расходы владельца уменьшают прибыль наравне с прочими.
