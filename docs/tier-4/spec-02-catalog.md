# SPEC-02. Каталог, штрихкоды, этикетки, справочники

## Задача

Справочник товаров с категориями и характеристиками, поиск по штрихкоду и тексту, создание собственных штрихкодов и печать этикеток; справочники сотрудников, услуг и поставщиков.

## Категории

- `kind`: `oil`, `filter`, `battery`, `other`. Масло (`oil`) всегда учитывается в миллилитрах, остальные — в штуках.
- `attributes` — список характеристик: `{key, label, type: text|number|select, options?, filterable}`. При создании категории каждого вида предлагаются стандартные:
  - масло: вязкость (select), основа (select: синтетика, полусинтетика, минеральное), допуски (text), объём тары задаётся полем товара;
  - фильтр: тип (select: масляный, воздушный, салонный, топливный), кросс-номера (text);
  - аккумулятор: ёмкость А·ч (number), пусковой ток (number), полярность (select).
- Эндпоинты: `GET/POST /categories`, `PATCH /categories/{id}`.

## Товары

- Поля: `name`, `brand`, `article`, `category_id`, `container_ml` (обязательно и > 0 для масла), `attrs` (значения по ключам категории), `barcodes[]`.
- Цены филиала: `sale_price_tyiyn` (за штуку или канистру), `pour_price_per_l_tyiyn` (только масло, меняет только владелец), `min_stock`.
- Эндпоинты:
  - `GET /products?q=&category_id=&attr.<key>=<value>&limit=` — поиск по названию, бренду, артикулу, штрихкоду (подстрока без учёта регистра) и фильтрам характеристик.
  - `GET /products/by-barcode/{code}` → товар или 404.
  - `GET /products/similar?name=` → до 5 товаров с близким названием (`pg_trgm`, сходство ≥ 0,3).
  - `POST /products`, `PATCH /products/{id}`, `PATCH /products/{id}/prices`.
  - `POST /products/{id}/barcodes {code?}` — добавить заводской код или, без `code`, создать внутренний.
- Ответ содержит остаток филиала (`stock_qty`), для масла — разбивку на канистры. Поля `avg_cost_tyiyn` и `stock_value_tyiyn` — только владельцу.
- Изменение цены пишется в журнал со старым и новым значением.

## Внутренний штрихкод

```
EAN-13: "22" + 10 цифр порядкового номера (счётчик филиала barcode_seq) + контрольная цифра
контрольная: сумма цифр на нечётных позициях (1-я, 3-я, …) ×1, на чётных ×3; check = (10 − сумма mod 10) mod 10
```
Код уникален глобально; если заводской код совпадает с существующим — 409 с указанием товара.

## Этикетки

- Настройка филиала `labels`: `{width_mm, height_mm, show_name, show_price, show_article}`; пресеты 58×40, 40×30, 30×20.
- `GET /settings/labels`, `PUT /settings/labels`.
- Клиент: выбор товара и количества копий → страница печати с CSS `@page { size: Wmm Hmm }`, штрихкод EAN-13 (или CODE128 для нестандартного кода), название, цена. Печать через диалог браузера.
- QR-код генерируется на клиенте для ссылок (используется в этапе 3).

## Справочники

- Сотрудники: `GET/POST /employees`, `PATCH /employees/{id}` — ФИО, кассир/мастер, активен.
- Услуги: `GET/POST /services`, `PATCH /services/{id}` — название, цена, начисление мастеру (по умолчанию 30 сом = 3000 тыйын).
- Поставщики: `GET/POST /suppliers`, `PATCH /suppliers/{id}`.
- Удаления нет, только деактивация.

## Клиент

- Экран «Товары»: поиск, фильтры по категории и характеристикам, карточка с остатком и ценами, кнопка «Этикетки».
- Создание товара: поле штрихкода (сканер), по мере ввода названия показываются похожие товары с предупреждением «возможно, уже заведён».
- Экраны справочников: категории, сотрудники, услуги, поставщики.
- Настройка этикеток с предпросмотром.

## Критерии приёмки

- [ ] Масло без `container_ml` не создаётся (422).
- [ ] Контрольная цифра: для `220000000001` → `2200000000019`.
- [ ] Повторный штрихкод даёт 409 с названием существующего товара.
- [ ] Администратор не меняет цену розлива (403) и не видит `avg_cost_tyiyn`.
- [ ] Поиск находит товар по части артикула и по штрихкоду.
- [ ] Похожие товары находятся при опечатке в названии.
