# SPEC-35. Коды из старой базы Умаг — везде

Замечание заказчика 26.10.2026: «я просил, чтобы товары по коду можно было найти именно из старой базы Умаг, а ты не сделал». Список старой программы (SPEC-20, `old_catalog`, 5 710 строк на точке: штрихкод у всех, «доп. код» у 811) сейчас подсказывает только в приходе, ревизии и сканере товаров; на кассе и в «Товарах» код Умага ничего не находит, и ни один товар учёта не связан со строкой Умага. Решение — ADR-110.

## 1. Связь товара со строкой Умага

- У строки Умага — ссылка на товар учёта (`old_catalog.product_id`). Все коды строки — штрихкод, артикул (если похож на код: только цифры и латиница без пробелов), каждый «доп. код» (через «;», «,» или пробел) — становятся кодами товара (`product_barcodes`, источник «Умаг»). После этого код Умага находит товар везде, где ищут по коду: скан и поиск на кассе, «Товары», приход, ревизия, перелив, брак, возврат поставщику, оприходование, этикетки — и в кассе без сети (коды товара уходят в снимок).
- Код, который уже есть у другого товара, не переносится: строка Умага получает отметку «конфликт кода» с названием того товара (виден на экране связывания), остальные её коды переносятся.
- Числовой код ищется и без потерянных Excel нулей впереди (как сейчас в `old_catalog/search`).
- Новая выгрузка Умага (замена списка) сохраняет связи: строка с тем же штрихкодом (или тем же доп. кодом) получает ту же ссылку; коды, уже перенесённые в товар, остаются у товара.

## 2. Где видны товары Умага

Уточнение заказчика 26.10.2026: «на кассе он не должен видеть товары Умага, а вот в разделе «Товары» или «Приход» должен видеть и с кодом должен читать».

- **Касса — товаров Умага не видно.** Ни блока Умага в поиске, ни окна «Завести из Умага». Касса находит только заведённые товары; код Умага связанного товара — его код (§1), поэтому скан такой наклейки на кассе находит товар. Незаведённый код на кассе — прежнее окно «Код не найден».
- **«Товары» и «Приход» (а также ревизия и «Сканер товаров», где список Умага был и раньше — SPEC-20, SPEC-29 §1)** — товары Умага видны и читаются по коду:
  - поиск по тексту показывает ниже своих товаров блок «Из старой базы Умаг» — строки, ещё не связанные с товаром (до 8), с «Завести»;
  - скан или ввод кода, которого нет у товаров, но который есть в Умаге: строка связана — берётся связанный товар; не связана — окно «Товар из старой базы Умаг»: название, цена продажи и закупки из Умага, поставщик, категория; «Завести» (полная карточка, заполненная из Умага — `presetFromHit`, SPEC-29 §2; после сохранения товар связан, все коды перенесены, в приходе строка добавлена) и «Это уже есть — выбрать товар» (поиск своего товара → связать). Без права «Товары и штрихкоды» (ADR-097) — только текст «Товар есть в базе Умаг, но не заведён: попросите владельца или администратора завести его».
  - Нигде нет — прежнее окно «Код не найден».
- Остальные выборы товара (перелив, брак, возврат поставщику, оприходование, подарки и т. п.) — как касса: только заведённые товары.
- Без сети: связанные коды работают (они у товара); несвязанная строка Умага в «Товарах»/«Приходе» — «Код есть в базе Умаг, завести товар можно, когда будет связь».

## 3. «Товары → Связать с Умагом» (владелец и право «Товары и штрихкоды»)

- Сводка: строк Умага, связано, не связано, конфликтов кодов.
- «Связать автоматически»: точное совпадение кода (штрихкод/доп. код Умага = код товара) или нормализованного названия (регистр, пробелы, кавычки, «ё»→«е») при единственном кандидате — связывает сразу и переносит коды; итог «связано N».
- «Похожие пары»: товары без связи и похожие строки Умага (сходство названий ≥ 0,45, бренд/объём совпадают, если есть) — список «товар ↔ строка Умага, сходство, цены», кнопки «Связать» и «Не то», страницы, поиск. «Не то» запоминается и больше не предлагается.
- У строки Умага — «Отвязать» (коды остаются у товара, пока их не уберут в карточке товара; журнал).
- В карточке товара — блок «Умаг»: связанная строка (название, коды, цена в Умаге), «Связать другую», «Отвязать».

## 4. Журнал и права

- Связать, отвязать, автосвязывание, «не то» — записи журнала `old_catalog.link`, `old_catalog.unlink`, `old_catalog.auto_link`, `old_catalog.reject`; с `op_id`, повтор — тот же ответ. Право — «Товары и штрихкоды» (владелец — всегда). Филиалы (SPEC-33): список Умага у филиала свой, товары и их коды общие.

## Проверка

- [ ] После связывания код Умага (штрихкод, доп. код, с потерянными нулями) находит товар: скан на кассе, поиск, «Товары», приход, ревизия, касса без сети.
- [ ] Касса: товаров Умага не видно (нет блока и окна Умага); код Умага связанного товара находит товар; незаведённый — «Код не найден».
- [ ] «Товары» и «Приход»: скан несвязанного кода Умага — окно «Товар из старой базы Умаг» → «Завести»: товар создан, связан, все коды у товара (в приходе — строка добавлена); «Это уже есть» — связать с выбранным; без права — только текст; блок Умага в поиске по тексту.
- [ ] Конфликт кода не крадёт код у другого товара; отметка видна.
- [ ] Автосвязывание: точный код и точное название при одном кандидате; похожие пары, «Связать» и «Не то» (не возвращается).
- [ ] Новая выгрузка Умага сохраняет связи; права и журнал; повтор `op_id`.
- [ ] Режим кассы: блока и окна Умага нет; скан кода Умага связанного товара добавляет товар.
