# SPEC-20. Работа с товарами: заведение по штрихкоду со списком старой программы

## Задача

Перенести товары из старой программы без дублей: выгрузка Excel служит подсказкой, а товар учёта появляется, только когда человек отсканировал его на полке и подтвердил карточку. Тот же экран — для пересчёта остатков при запуске (решение заказчика, ADR-056).

## Список старой программы

- Владелец загружает выгрузку «Список товаров» (.xlsx) на экране «Работа с товарами». Файл читается в браузере, на сервер уходят строки: название, штрихкод, артикул, доп. код, закупка, цена продажи, единица, поставщик, категория. Новая загрузка заменяет прежнюю.
- Строки «Новый продукт» и без названия отбрасываются. Суммы переводятся в тыйыны целыми (округление до тыйына).
- Из списка товары не создаются: это справочник подсказок (`old_catalog`).

## Экран «Работа с товарами»

С SPEC-29 §10 — вкладка «Сканер товаров» экрана «Ревизия и товары» (`/revision?tab=scan`; прежний адрес `/intake` ведёт туда же).


- Поле скана в фокусе. Сканер дочитал код (цифры и пауза 150 мс) — поиск запускается сам, Enter не нужен; Enter тоже работает.
- Товар с этим кодом уже есть — «Уже заведён»: название, остаток, цена.
- Нет — поиск в списке старой программы по штрихкоду, артикулу, доп. коду. Нашёлся — карточка заполняется сама: название, цена, закупка; для масла (единица «литр») объём тары берётся из названия («4L», «200Л»), цена и закупка за литр пересчитываются за канистру (бочку). Розлив за литр отдельно не вводится: он считается от цены канистры и показан рядом с ней (ADR-074), у тары из старого списка он равен цене литра старой программы с точностью до тыйына.
- Нет и там — новая карточка со штрихкодом; пока пишут название, слева подбираются позиции старого списка, щелчок заполняет карточку.
- Над карточкой — «Похоже, такой товар уже заведён» (похожие названия): «Это он — привязать код» добавляет штрихкод существующему товару вместо дубля.
- Категория запоминается: следующая карточка открывается с той же.
- Закупка из карточки записывается как последняя закупочная цена товара (`initial_cost_tyiyn`): по ней ревизия оценит найденный остаток, если прихода ещё не было.

## Режим пересчёта

- Переключатель «Пересчёт (ревизия)». Включён — у найденного или нового товара поле «На полке, шт / л». Количество записывается в открытый черновик ревизии «весь склад» (или новый). Владелец проводит ревизию (SPEC-15) — остатки встают, излишек оценивается по закупке.
- Товар уже считали в этой ревизии (лежит на второй полке) — экран показывает «уже посчитано N» и спрашивает: «Прибавить к N» (по умолчанию, Enter) или «Заменить». Привязка кода к заведённому товару прибавляет (ADR-059).

## API

- `GET /old-catalog` → сколько строк и когда загружен. `PUT /old-catalog [строки]` — заменить, только владелец, до 50 000 строк.
- `GET /old-catalog/search?barcode=&q=` → до 20 подсказок: точное совпадение кода сверху, затем похожие названия; у каждой — заведён ли уже товар с этим кодом.
- `POST /products` + `initial_cost_tyiyn`.

## Критерии приёмки

- [x] Скан кода из списка старой программы заполняет карточку без Enter; повторный скан показывает «Уже заведён».
- [x] Масло: объём из названия, цена за литр → за канистру.
- [x] «Новый продукт» и пустые строки не загружаются; загрузку меняет только владелец.
- [x] Похожий товар — привязать код вместо дубля.
- [x] Пересчёт попадает в черновик ревизии.

## Дополнено SPEC-35 (26.10.2026)

- Строка списка — строка старой базы Умаг — связывается с товаром учёта (`old_catalog.product_id`); её коды (штрихкод, артикул, похожий на код, каждый «доп. код») становятся кодами товара — по ним товар находят касса, приход, ревизия и касса без сети. Числовой код находится и без нулей впереди, потерянных Excel.
- Карточка, заведённая из строки, связывается с ней в той же операции (`POST /products` с `old_catalog_id`, право «Товары и штрихкоды»); «Это он — привязать код» тоже связывает строку. Скан кода связанной строки показывает её товар («Уже заведён»), у подсказки — «заведён: название».
- `GET /old-catalog/search` — у подсказки ещё `product_id`, `product_name`, `codes`, `conflicts`; не заведённые строки — выше. `GET /old-catalog` — ещё `linked`, `unlinked`, `conflicts`. `PUT /old-catalog` сохраняет связи и отвечает `{rows, linked, copied}`; сообщение о загрузке говорит, сколько связей сохранено.
- Связать товары со строками целиком — экран «Товары → Связать с Умагом» (SPEC-35 §3).
