# SPEC-16. Масляная книжка

## Задача

История замен масла по каждой машине клиента: когда меняли, какое масло и фильтр, на каком пробеге и когда следующая замена. Касса показывает это, как только выбрали машину; владелец видит в карточке клиента, фирма — в своём кабинете (SPEC-12). Это справочные данные, а не учёт денег: пробег и интервал правятся.

## Данные

```
party_vehicles + interval_km (по умолчанию 8 000), interval_months (по умолчанию 6)
oil_changes (id, branch_id, vehicle_id, party_id, sale_id?, change_date, mileage_km?,
             oil_text, filter_text, comment, user_id, created_at, updated_at)
```

`oil_text` и `filter_text` — что залили и что поставили, строкой из чека («Totachi Niro LV 0W-20, 4 л · 1 кан.»): запись читается и после переименования товара. Следующая замена не хранится, а считается: пробег + `interval_km`, дата + `interval_months`.

## Как появляется запись

- Чек «В сервис» с выбранной машиной клиента — запись создаётся в той же транзакции, что и чек. Масло — строки товаров из категорий масел, фильтр — строки фильтров. Пробег касса спрашивает полем «Пробег, км» рядом с машиной (необязательно).
- Если в чеке нет ни масла, ни фильтра, записи нет: это не замена.
- Чек вернули целиком — запись из книжки скрывается.
- Старые замены из тетради заводятся вручную: дата, пробег, что залили.

## API

- `GET /vehicles/{id}/oil-book` → машина, интервал, записи (свежие сверху), следующая замена по пробегу и дате.
- `GET /parties/{id}/oil-book` → то же по всем машинам клиента.
- `PATCH /vehicles/{id}/oil-settings {interval_km, interval_months}` — интервал машины.
- `POST /vehicles/{id}/oil-changes {change_date, mileage_km?, oil_text, filter_text?, comment?}` — запись из тетради.
- `PATCH /oil-changes/{id} {mileage_km?, comment?}` — поправить пробег или комментарий (в журнал).
- Кабинет фирмы: `GET /client/oil-book`.

Права: владелец и администратор. Цены и себестоимость в книжке не показываются.

## Клиент

- Касса: выбрали машину — под ней «Прошлая замена 12.07: Totachi 0W-20, 85 000 км · следующая на 93 000 км или до 12.01», в сервисе — поле «Пробег, км».
- Карточка клиента: блок «Масляная книжка» по машинам, с правкой пробега, интервала и записью из тетради.
- Кабинет фирмы: вкладка «Машины».

## Критерии приёмки

- [x] Чек «в сервис» с машиной и маслом создаёт запись с маслом, фильтром и пробегом.
- [x] Следующая замена = пробег + интервал машины, дата + месяцы интервала.
- [x] Чек без масла и фильтра запись не создаёт; полностью возвращённый чек из книжки пропадает.
- [x] Пробег и интервал правятся, запись из тетради заводится вручную.
