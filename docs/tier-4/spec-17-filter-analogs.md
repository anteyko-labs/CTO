# SPEC-17. Аналоги фильтров по кросс-номерам

## Задача

У одного фильтра много номеров: оригинальный артикул и номера других производителей (кросс-номера). Клиент приходит с номером со старого фильтра или просит «Toyota 90915-YZZE1», а на полке Mann W 712/75 — это тот же фильтр. Касса должна находить товар по любому из номеров и подсказывать замену, когда нужного нет на складе.

## Данные

```
product_cross_numbers (product_id, code, code_norm)   -- primary key (product_id, code_norm)
```

`code_norm` — номер без пробелов, дефисов, точек и косых, в верхнем регистре: «90915-YZZE1», «90915 yzze1» и «90915YZZE1» — один номер. Аналоги — товары, у которых совпадает хотя бы один номер: кросс-номер одного равен кросс-номеру или артикулу другого. Связь симметричная: достаточно записать номера у одного из товаров.

## API

- `PUT /products/{id}/cross {codes: [..]}` — заменить список кросс-номеров (владелец и администратор, как карточку товара); в журнал.
- `GET /products/{id}/cross` — список номеров.
- `GET /products/{id}/analogs` → аналоги с остатком и ценой продажи (без себестоимости), сначала те, что есть на складе.
- Поиск товаров (`GET /products?q=`) находит и по кросс-номеру: «90915yzze1» найдёт фильтр, у которого этот номер записан кросс-номером.

## Клиент

- Карточка товара: поле «Кросс-номера» — через запятую или с новой строки.
- Касса: под строкой фильтра — «Аналоги: Mann W 712/75 — 20 шт, 600 с» с кнопкой «Заменить». Если нужного не хватает на складе, подсказка выделена: «нет на складе — есть аналог».

## Критерии приёмки

- [x] Кросс-номер в любом написании находит товар поиском.
- [x] Аналоги видны в обе стороны, остаток и цена без себестоимости.
- [x] Касса предлагает аналог, когда товара не хватает, и меняет строку одним нажатием.

## Дополнено задачей 002 (31.10.2026, П10, ADR-{B3.2})

- «Подобрать кросс-номера» — в карточке фильтра (с правом «Товары») и «Кросс-номера» у категории фильтров (по товарам по очереди, «Остановить», можно пропускать товары с номерами). Номера подбирает сервис разбора (как накладные по фото, ADR-098) по названию, бренду, артикулу и типу.
- «Настройки → Кросс-номера» (владелец): «записывать сразу» (по умолчанию) — номера сразу в карточке; «предлагать» — с галочками, сохраняет человек. Каждая запись — в журнале с пометкой «подобрано автоматически», в карточке — строка «Подобрано автоматически: …»; лишний номер убирается в карточке. Подборов в день на филиал — 50 (0 — выключено); исчерпано — 409 с подсказкой.
- Свой артикул, уже записанные номера и повторы в любом написании не записываются; сервис не ответил — номера не тронуты; без ключа сервиса — 422; повтор `op_id` — тот же ответ.
- Маршруты: `POST /api/v1/products/{id}/cross/pick`, `GET/PUT /api/v1/settings/cross-pick`; `GET/PUT /products/{id}/cross` — поле `auto`. Проверки: `server/tests/cross_pick.rs`, `web/src/lib/crossPick.test.ts`.
