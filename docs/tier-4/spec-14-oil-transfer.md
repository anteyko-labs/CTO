# SPEC-14. Перелив масла

## Задача

Владелец переливает масло из одного товара в другой: например, остаток Totachi из бочки — в Hi-Tec. Остаток и его стоимость переходят к получателю, себестоимость литра у получателя сразу становится средневзвешенной (ADR-011). Операция только владельца (инвариант 14). Решение заказчика от 2026-10-09.

Пример заказчика: в Hi-Tec было 5 л по 100 с, долили 50 л по 200 с → 55 л на 10 500 с, то есть 190,91 с за литр.

## Данные

```
oil_transfers (id, branch_id, number, from_product_id, to_product_id, qty_ml, value_tyiyn,
               comment, user_id, device_id, created_at)                       -- неизменяемая
```

Движения склада — две строки `stock_movements` с `doc_type = oil_transfer`: у источника `−qty_ml, −value`, у получателя `+qty_ml, +value`. Остаток по-прежнему равен сумме движений (инвариант 6).

## Проведение

`POST /oil/transfers {op_id, from_product_id, to_product_id, qty_ml, comment?}`

```
в run_operation:
  только владелец, иначе 403
  оба товара — масло (unit = ml), разные, иначе 422
  qty_ml > 0 и не больше остатка источника, иначе 422
  lock остатков обоих товаров в порядке id
  value = cost_of(qty_ml, пул источника)   -- весь остаток = вся его стоимость
  insert oil_transfers (number = next(oil_transfer))
  apply_movement(источник, −qty_ml, −value); apply_movement(получатель, +qty_ml, +value)
  audit oil.transfer {number, from_name, to_name, qty_ml, value, avg_per_l}
  ответ: перелив, остаток и средняя за литр у источника и у получателя
```

Цены продажи получателя (канистра, розлив за литр) перелив не меняет: после проведения экран сразу предлагает их поправить, сохранение идёт обычной правкой цен владельцем (ADR-032), с уведомлением.

`GET /oil/transfers` → последние переливы с признаком «отменён». Только владелец.

`POST /oil/transfers/{id}/reverse { op_id, comment }` — отмена перелива (ADR-052). Только владелец, причина обязательна. Перелитое возвращается в источник той же стоимостью, с какой ушло; у получателя снимаются те же литры и та же стоимость. Если в получателе осталось меньше перелитого (уже продано), отмена отклоняется — тогда переливают обратно. Документ перелива не меняется: отмена — отдельная запись `oil_transfer_reversals`, движения `oil_transfer_reversal`, уведомление владельцу.

## Клиент

- Пункт меню «Перелив» в разделе «Склад», виден только владельцу.
- Выбор «Из масла» (только с остатком) и «В масло», литры — по умолчанию весь остаток источника.
- До проведения видно: себестоимость литра источника, сколько и почём сейчас у получателя и что станет после.
- После проведения — себестоимость литра и канистры у получателя и поля новых цен продажи.
- История переливов, у каждого — «Отменить» с причиной; отменённые зачёркнуты.

## Критерии приёмки

- [x] 5 л по 100 с + 50 л по 200 с → 55 л, 190,91 с за литр, стоимость остатка 10 500 с.
- [x] Администратору → 403.
- [x] Больше остатка источника → 422.
- [x] Остатки сходятся с движениями после перелива.
- [x] Отмена возвращает источник и получателя к значениям до перелива; повторная отмена — 409.
- [x] Перелитое уже ушло из получателя — отмена 422.
